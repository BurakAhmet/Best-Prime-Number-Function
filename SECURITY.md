# Security Policy

This file is the repository-root copy of the security policy. The copy GitHub’s
Security tab and community checklist use is
[`.github/SECURITY.md`](.github/SECURITY.md).

## Supported Versions

Security updates are applied on the default branch (`main`).

| Version | Supported |
| ------- | --------- |
| `main` (latest) | :white_check_mark: |
| Older tagged releases | :x: (best-effort only) |

## Reporting a Vulnerability

**Do not** open a public GitHub issue for exploitable flaws.

1. **Preferred:** [Report a vulnerability](https://github.com/BurakAhmet/Best-Prime-Number-Function/security/advisories/new)
   (private vulnerability reporting)
2. Or email **ahmetburakbicer@gmail.com**

Full scope, out-of-scope notes, and expected response: see
[`.github/SECURITY.md`](.github/SECURITY.md).
